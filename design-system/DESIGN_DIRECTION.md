# KNOW/OS — Direção de Design

## Status

Direção aprovada e congelada: **Brutalismo Técnico + voz editorial**.

## Tese visual

A interface se apresenta como instrumento de estudo: estrutura visível,
tipografia como hierarquia, bordas explícitas e decoração mínima. A leitura
correta não é “plataforma de cursos”; é **bancada de conhecimento**:
caderno de laboratório + IDE + documentação técnica.

O usuário deve sentir que está construindo um mapa honesto do que sabe.

## Princípios

1. **Foco primeiro.** Hoje responde: “o que aprender, praticar ou revisar agora?”.
2. **Estrutura é o ornamento.** Grid, borda, alinhamento e tipografia criam identidade.
3. **Conhecimento e máquina possuem superfícies distintas.** Leitura é editorial clara; execução é técnica escura.
4. **XP não é Mastery.** Esforço e evidência de conhecimento são sistemas separados.
5. **Erro é evidência.** Falhar gera contexto para revisão, não punição visual.
6. **Movimento é resposta.** Animação existe para mostrar mudança de estado.
7. **Acessibilidade vence estética.** Toda expressão brutalista precisa continuar legível, navegável e operável.

## Direções rejeitadas

- neo-brutalismo infantil ou excessivamente colorido;
- dashboard escuro de analytics;
- cards SaaS arredondados;
- glassmorphism, gradientes e sombras difusas;
- mascote ou emoji como linguagem principal;
- dark mode completo;
- gamificação que concorra com aprendizado.
