# 04 — Core UX Flows

## Continue learning

Today → Continue → Lesson step → Activity/checkpoint → completion state → next recommendation.

The user may navigate freely. Prerequisites generate recommendations and warnings, not artificial locks.

## Practice

Practice → choose recommended/concept/mistake/project session → focused activities → feedback → session summary → evidence updates.

## Review

Review queue → focused concept recall → answer before seeing source material → feedback → next review date → session summary.

## Programming activity

Open activity → edit → RUN freely → inspect output/errors → iterate → SUBMIT SOLUTION → validate tests → record immutable Attempt → update evidence/history/eligible XP.

RUN never creates an official Attempt.

## Import

Select/drop Pack → parse → validate → preview → duplicate/version detection → diff → conflict resolution → atomic import → result summary.

## Export teacher context

Choose data categories → preview privacy and estimated size → copy or export structured context.

## Recover from error

Error states explain what failed, preserve user input, expose a retry path and avoid blame-oriented language.
