# ADR 0009 — Treat the approved Design System as normative

Status: Accepted
Date: 2026-07-30

## Context

KNOW/OS needs a durable decision for this concern before implementation.

## Decision

Agents need deterministic design guidance rather than interpreting prototypes independently.

## Consequences

Implementation consumes canonical tokens and precedence rules; divergence requires documentation.

## Review trigger

Revisit only when new evidence materially changes scale, security, product scope or implementation feasibility.
