# ADR 0010 — Keep AI optional to the core

Status: Accepted
Date: 2026-07-30

## Context

KNOW/OS needs a durable decision for this concern before implementation.

## Decision

Learning, review, execution, Packs and history must remain reliable, testable and affordable without an external model.

## Consequences

AI-enhanced features are adapters and cannot own canonical mastery or user state.

## Review trigger

Revisit only when new evidence materially changes scale, security, product scope or implementation feasibility.
