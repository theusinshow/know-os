# ADR 0007 — Use deterministic explainable mastery

Status: Accepted
Date: 2026-07-30

## Context

KNOW/OS needs a durable decision for this concern before implementation.

## Decision

Users must understand why a concept has a state. An opaque AI score would be difficult to test and trust.

## Consequences

Policies and evidence weights require versioning and comprehensive tests.

## Review trigger

Revisit only when new evidence materially changes scale, security, product scope or implementation feasibility.
