# ADR 0004 — Use stable IDs and versioned portable Packs

Status: Accepted
Date: 2026-07-30

## Context

KNOW/OS needs a durable decision for this concern before implementation.

## Decision

Learning content needs idempotent import, update previews and portability.

## Consequences

Schema compatibility and fixtures become permanent maintenance responsibilities.

## Review trigger

Revisit only when new evidence materially changes scale, security, product scope or implementation feasibility.
